# probe-backend.mjs

## Назначение
Диагностика готовности бэка КИП Спецтехники. Запускается из CLI с любым URL —
прогоняет ключевые endpoint'ы из ТЗ и печатает табличку статусов. Нужен, чтобы
**за 5 секунд понять**, отвечает ли вообще сервер, есть ли публичные справочники,
работает ли логин, какие из защищённых ручек реально вернут данные.

## Когда запускать
- Сразу как сисадмин говорит «бэк живой» — до переключения `VITE_USE_MOCKS=false`.
- При любом подозрении, что бэк отдаёт не то — без открытия Network в браузере.
- На сервере (через `localhost:3500`), чтобы отличить сервис vs сеть.

## Входы
| Аргумент | Обязательно | Пример | Что делает |
|---|---|---|---|
| `<BASE_URL>` | да | `http://2.27.86.52:3500` | Базовый URL бэка |
| `--phone <phone>` | нет | `+79001111111` | Телефон водителя для пробного логина |
| `--pin <pin>` | нет | `1111` | PIN водителя |

Если `--phone`+`--pin` переданы — скрипт логинится и проверяет защищённые ручки
с реальным токеном. Если нет — авторизованный блок пропускается.

## Выходы
- stdout — таблица с колонками: статус-флажок (`OK` / `!!` / `ERR`) · HTTP-код ·
  время в мс · endpoint · превью тела (первые 120 символов JSON).
- exit code: `0` если что-то ответило, `1` если совсем нет TCP-коннекта, `2` —
  неверные аргументы.

## Как запускать
```bash
# Из директории kip-frontend
node scripts/probe-backend.mjs http://2.27.86.52:3500

# Через npm-скрипт (alias)
npm run probe -- http://2.27.86.52:3500

# С тестовым логином
node scripts/probe-backend.mjs http://2.27.86.52:3500 --phone +79001111111 --pin 1111

# С сервера через localhost
ssh server "cd /opt/claudeclaw/kip-spetstehnika && node ../path/to/probe-backend.mjs http://localhost:3500"
```

## Что проверяет (порядок)
1. **Reachability** — `GET /health`, `GET /`. Если оба = `000` → нет TCP, дальше
   нет смысла.
2. **Публичные справочники** — `/api/drivers`, `/api/equipment`, `/api/sites`,
   `/api/legal-entities`. Должны отдавать массивы без авторизации.
3. **Логин водителя** — `POST /api/auth/driver/login`. Если ОК — кладём токен в
   память.
4. **Защищённые ручки** — `/api/shifts/my`, `/api/shifts`, `/api/work-days`,
   `/api/expenses`, `/api/incidents`. С `Bearer <token>`.

## Зависимости
- Node 18+ (нативный `fetch`).
- Без npm-зависимостей.
- Кроссплатформенный (Windows / Linux / macOS).

## Что НЕ делает
- Не делает мутаций (`POST /api/shifts`, `POST /api/work-days` и т.п.) — чтобы не
  засорять прод-БД. Для проверки мутаций есть e2e сценарии через UI.
- Не парсит multipart, не загружает фото.
- Не проверяет PWA-кэш и offline-очередь — это уровень браузера.
